# Newton/Warp 및 Actuator 모델

> **참고**
>
> 이 문서는 Newton과 Warp의 모든 기능을 일반적으로 설명하는 문서가 아니라,
> 본 프로젝트의 **무부하 단일 서보 모터 디지털 트윈 구성과 파라미터 식별**에
> 필요한 개념을 중심으로 정리한다.
>
> 따라서 Actuator 구성, 물리 파라미터 및 식별 대상에 관한 내용은
> 단일 회전축과 무부하 시험 조건을 기준으로 한다.

> **현재 모터 모델 구현과의 관계**
>
> 이 문서는 Newton의 actuator 및 물리 파라미터 개념을 이해하기 위한 `study` 문서이다.  
> 현재 프로젝트의 실제 구현은 Newton 기본 actuator를 그대로 사용하는 방식이 아니라, `single_motor_twin.py`에서 지연, PID 제어, 토크 제한, 마찰 등의 일부 요소를 직접 계산하여 Newton 물리계에 반영하는 방식으로 구성하였다.

## 1. 디지털 트윈과 그레이박스 시스템 식별

### 1.1 디지털 트윈

디지털 트윈은 실제 장비의 동작 특성을 소프트웨어 모델로 표현한 것이다.

본 프로젝트에서는 WMX3의 Command Position을 Newton 트윈에 입력하고,
실제 단일 서보 모터와 유사한 위치·속도·토크 응답이 나타나도록
Newton의 제어 및 물리 파라미터를 조정한다.

### 1.2 시스템 식별과 그레이박스 모델

시스템 식별은 실측 데이터를 기준으로 모델의 불확실한 파라미터를 추정하는 과정이다.

그레이박스 모델은 실제 시스템에 대한 물리적 구조는 알고 있지만,
정확한 파라미터 값은 알 수 없을 때 실측 데이터를 이용해 해당 값을 추정하는 모델이다.

단일 무부하 서보 모터를 Newton에 모사하기 위해 미리 가정한 모델 구조는 [`프로젝트 전체 구조`](../guideline/01_project_overview.md)의 `3.2 Newton 트윈의 모사 흐름` 을 참고한다.

## 2. Newton과 Warp의 역할

### 2.1 Newton

Newton은 로봇과 기계 시스템의 물리 모델을 구성하고,
시간에 따른 동역학을 계산하기 위한 시뮬레이션 프레임워크이다.

물리 모델, 상태, 제어 입력 및 Solver를 구성하고 시뮬레이션 흐름을 관리한다.

### 2.2 Warp

Warp는 Newton의 물리 계산을 실제로 실행하는 하위 계산 프레임워크이다.

Newton에서 정의한 배열 연산과 계산 커널을 CPU 또는 GPU에서 실행한다.

본 프로젝트에서는 Warp의 실행 장치를 CPU로 설정하여 Newton 시뮬레이션을 수행한다.

### 2.3 Newton과 Warp의 관계

Newton과 Warp의 관계는 다음과 같이 정리할 수 있다.

```text
사용자 코드
- 1-DOF 모델 구성
- Actuator 및 파라미터 설정
- Command Position 입력
        ↓
Newton
- 모델 및 시뮬레이션 구성
- 제어 및 동역학 계산 정의
- Solver 실행 관리
        ↓
Warp
- 배열과 계산 커널 처리
- CPU 또는 GPU에서 실제 연산 수행
        ↓

시뮬레이션 결과
```

## 3. ModelBuilder에서 Solver까지의 실행 흐름

Newton 시뮬레이션은 모델을 구성한 뒤,
Solver를 반복 실행하여 시간에 따른 상태 변화를 계산한다.

```text
ModelBuilder
- 물체와 관절 구성
- 물리 파라미터와 Actuator 설정
        ↓
finalize() 
- ModelBuilder에 임시로 쌓아 둔 설정을 실제 시뮬레이션용 Model로 확정하는 함수
        ↓
Model
- 시뮬레이션에 사용할 구조와 파라미터 저장
  (= Solver가 실제로 계산할 완성된 모델)
        ↓
State / Control 생성
- State: 현재 위치와 속도 등의 동적 상태
- Control: 목표 위치와 제어 입력
        ↓
Command Position을 Control에 설정
        ↓
Solver.step()
- 현재 State와 Control을 이용하여 다음 시점의 상태 계산
        ↓
다음 시간 구간 계산
        ↓
시뮬레이션 종료 시점까지 시간 간격마다 반복

시뮬레이션 간격이 1ms 라면, Solver.step() 한 번이 1ms 뒤의 위치와 속도 등을 계산하는 것.
```

## 4. Actuator 및 물리 파라미터

Newton의 Actuator는 목표 상태와 현재 관절 상태를 이용하여
관절에 적용할 힘 또는 토크를 계산한다.

본 프로젝트에서는 회전 관절을 사용하므로 Actuator의 출력은 토크이다.

```text
목표 위치·속도
    ↓
Delay
    ↓
Controller
    ↓
Clamping
    ↓
관절 입력 토크
```

| 구성 요소 | 역할 |
|---|---|
| `Delay` | 입력 지령을 지정된 계산 단계만큼 지연한다. |
| `Controller` | 목표 상태와 현재 상태의 오차를 이용하여 토크를 계산한다. |
| `Clamping` | 계산된 토크를 모터의 출력 한계에 맞게 제한한다. |

Actuator가 계산한 토크는 Solver의 입력으로 사용되며,
동시에 현재 모터가 발생시키는 제어 토크 신호로 기록할 수 있다.

### 4.1 Controller

위치 제어에는 PD 또는 PID Controller를 사용할 수 있다.

| 파라미터 | 의미 |
|---|---|
| `kp` | 위치 오차에 대한 비례 게인 |
| `ki` | 위치 오차 누적에 대한 적분 게인 |
| `kd` | 속도 오차에 대한 미분 게인 |
| `integral_max` | 적분항의 과도한 누적을 제한하는 값 |

### 4.2 Clamping

Controller가 계산한 토크는 Clamping을 통해
모터의 출력 범위 안으로 제한된다.

- `ClampingMaxEffort`: 최대 토크 제한
- `ClampingDCMotor`: 회전 속도에 따른 가용 토크 감소 특성 근사

실제 적용 방식과 정확한 파라미터 이름은
사용하는 baseline 코드와 Newton 버전을 기준으로 확인한다.

### 4.3 Actuator와 물리 모델의 구분

관성과 마찰은 Actuator 내부 요소가 아니라
링크와 관절의 물리 속성으로 설정된다.

| 물리 특성 | 관련 속성 |
|---|---|
| 링크 질량 및 관성 | `mass`, `inertia` |
| 관절축 유효 관성 | `joint_armature` |
| 쿨롱 마찰 | `joint_friction` |
| 수동 감쇠 | `joint_damping` |

Actuator는 관절에 적용할 토크를 계산하고 제한한다.

Solver는 해당 토크와 관성·감쇠·마찰을 이용하여
다음 시점의 관절 위치와 속도를 계산한다.

## 5. 프로젝트의 주요 식별 대상

Newton 트윈을 forward model로 사용하여,
WMX3에서 측정한 위치·속도·토크 응답과 유사한 응답이 나오도록
Newton의 제어 및 물리 파라미터를 추정한다.

### 5.1 제어기와 기계 플랜트 모델

단일 회전축의 기계 동역학은 개념적으로 다음과 같이 표현할 수 있다.

```text
J·q̈ + b·q̇ + τc·sign(q̇) = τ_motor
```

| 기호 | 의미 |
|---|---|
| `J` | 모터와 회전체의 유효 관성 |
| `b` | 속도에 비례하는 점성 감쇠 계수 |
| `τc` | 운동 방향의 반대로 작용하는 쿨롱 마찰 토크 |
| `τ_motor` | Actuator가 계산하여 관절에 적용하는 토크 |

서보 드라이브의 제어 응답은 PD 또는 PID Controller로 근사한다.

먼저 지연된 목표 위치와 현재 위치의 차이로 위치 오차를 계산한다.

```text
위치 오차 e = 지연된 목표 위치 q_cmd - 현재 위치 q
```
Controller는 위치 오차와 속도 오차를 이용하여 토크를 계산한다.

```text
제한 전 토크 τ_raw = Kp × 위치 오차 + Ki × 위치 오차 누적값 + Kd × 속도 오차
```
여기서 속도 오차는 다음과 같다.

```text
속도 오차 = 목표 속도 q̇_cmd - 현재 속도 q̇
```

마지막으로 Clamping을 적용하여 토크를 최대 토크 범위 안으로 제한한다.


목표 속도가 0인 위치 제어에서는 미분항이
개념적으로 `-Kd × 현재 속도` 형태가 된다.

### 5.2 선형 소신호 해석

토크 포화, 쿨롱 마찰 및 지연을 무시하면
PD 제어를 사용하는 단일 회전축의 폐루프 응답은
개념적으로 다음과 같은 2차계로 표현할 수 있다.

```text
                     Kp
q / q_cmd = ─────────────────────
            J·s² + (b + Kd)·s + Kp

고유진동수: ωn = √(Kp / J)
감쇠비:     ζ = (b + Kd) / (2√(Kp·J))
```

`Kp`와 `J`는 주로 응답 속도에 영향을 주고,
`Kd`와 `b`는 감쇠와 오버슈트에 영향을 준다.

PID 제어에서는 적분항이 추가되어 3차계 특성을 갖는다.

이 해석은 파라미터의 영향을 이해하기 위한 직관이며,
실제 식별은 지연, 토크 제한 및 쿨롱 마찰을 포함한
Newton 시간영역 시뮬레이션으로 수행한다.

### 5.3 식별 대상과 고정 대상

| 구분 | 파라미터 | Newton 대응 | 처리 |
|---|---|---|---|
| 제어 게인 | `Kp`, `Ki`, `Kd`, `integral_max` | PD/PID Controller | 식별 |
| 지령 지연 | `delay_steps` | `Delay` | 식별 |
| 유효 관성 | `J` | 링크 관성, `joint_armature` | 식별 |
| 점성 감쇠 | `b` | `joint_damping` | 식별 |
| 쿨롱 마찰 | `τc` | `joint_friction` | 식별 |
| 최대 토크 | `τmax` | `ClampingMaxEffort` | 데이터시트 값으로 고정 |
| 토크–속도 특성 | 최대 속도와 가용 토크 | `ClampingDCMotor` 등 | Actuator 구조 항목, 식별 여부는 baseline 및 장비 사양 확인 |

PD Controller를 사용하는 경우에는
`Ki`와 `integral_max`를 제외한다.

무부하 단일 축에서는 지령 지연과 마찰의 영향이 비교적 잘 나타날 수 있지만,
최대 토크는 포화 구간이 발생하지 않으면 식별하기 어렵다.

따라서 최대 토크는 데이터시트 값으로 고정한다.
드라이브의 마찰 보상이 활성화된 경우 식별되는 마찰값은
모터 자체의 마찰이 아니라 제어 효과가 포함된 등가 마찰값으로 해석한다.

### 5.4 식별성을 높이기 위한 데이터

위치 응답만 사용하면 `Kp`와 `J`처럼
서로 유사한 영향을 주는 파라미터를 분리하기 어렵다.

Feedback Torque를 함께 사용하면 다음 관계를 추가로 비교할 수 있다.

```text
토크 ↔ 가속도·속도
→ 유효 관성 및 마찰 식별

토크 ↔ 위치·속도 오차
→ 제어 게인 식별
```

따라서 위치·속도·토크 신호를 함께 사용하여 피팅한다.
