# 프로젝트 전체 구조

## 1. 프로젝트 목적과 범위

### 1.1 프로젝트 목적
WMX3 Data Log로 취득한 무부하 단일 서보 모터의 입력(Command Position)과 출력(Feedback Position·Velocity·Torque) 데이터를 기준으로  
Newton 엔진 상에서 단일 모터 디지털 트윈의 파라미터를 피팅하여 실제 모터의 응답 특성을 재현하는 프로젝트이다.

### 1.2 왜 Newton을 쓰는가
Movensys는 로봇팔 제어 소프트웨어의 백그라운드 시뮬레이터로 Isaac Sim/PhysX 계열 환경을 사용하고 있다.  
하지만 현재 환경은 End-Effector가 상호작용할 대상이 주로 강체(rigid body)이다.

**Newton은 강체뿐 아니라 deformable object도 함께 다룰 수 있는 시뮬레이션 확장 가능성**이 있기 때문에,  
향후 로봇팔과 변형 물체가 함께 있는 장면을 다루기 위한 후보 엔진으로 검토할 가치가 있다.

### 1.3 왜 단일 무부하 서보 모터부터 시작하는가
최종적으로는 로봇팔 전체를 Newton 안에서 디지털 트윈해야 하지만,
실제 로봇팔 수준에서는 식별해야 할 제어 및 물리 파라미터가 너무 많아 초기 단계에서 바로 다루기 어렵다.  
그래서 본 프로젝트는 가장 단순한 단위인 무부하 단일 서보 모터부터 시작한다.

### 1.4 프로젝트 범위
해당 프로젝트는 실제 서보 시스템 전체를 복제하는 것이 아닌, 무부하 단일 모터의 입력-출력 응답을 Newton 기반 디지털 트윈으로 근사하는 것을 목표로 한다.

Newton 트윈은 실제 장비의 모든 내부 구조를 복제하는 모델이 아니라,
Command Position에 대한 위치·속도·토크 응답을 유사하게 재현하기 위한 그레이박스 모델이다.


## 2. 시스템 구성 요소와 역할 경계

| 구성 요소 | 역할 |
|---|---|
| WMX3 마스터 | 이동 궤적을 생성하고, 매 통신 주기마다 CSP 방식의 Command Position을 서보 드라이브에 전송한다. 드라이브에서 전달받은 피드백 신호를 Data Log로 저장한다. |
| EtherCAT | WMX3 마스터와 서보 드라이브 사이에서 위치 지령과 피드백 데이터를 주기적으로 전달한다. |
| 서보 드라이브 | 수신한 Command Position을 내부 위치·속도·전류 제어 루프로 추종하고 모터 구동 토크를 발생시킨다. |
| 서보 모터 | 드라이브가 발생시킨 토크에 따라 회전하며, 관성과 마찰에 의해 실제 응답이 결정된다. |
| Newton 디지털 트윈 | 드라이브와 모터에서 나타나는 지연, 제어 응답, 제한, 관성 및 마찰을 파라미터로 근사한다. |


## 3. 전체 제어 흐름

이 프로젝트의 전체 흐름은 실제 서보 모터의 응답을 WMX3 Data Log로 취득하고,
동일한 Command Position을 Newton 트윈에 입력한 뒤,
두 시스템의 출력 차이가 작아지도록 트윈의 파라미터를 조정하는 과정으로 구성된다.

### 3.1 실제 장비의 제어 흐름

WMX3 마스터는 이동 궤적을 생성하고,
각 EtherCAT 통신 주기마다 CSP 방식으로 Command Position을 서보 드라이브에 전송한다.

```text
WMX3 마스터
- 이동 궤적 생성
- CSP Command Position 전송
        ↓
EtherCAT 통신
- 위치 지령 전달
- 통신 및 연산 지연 발생 가능
        ↓
서보 드라이브 내부 폐루프 제어
- 수신한 Command Position 추종
- 내부 위치·속도·전류 제어 루프 수행
- 모터 구동 토크 발생
        ↓
드라이브 제한 조건
- 최대 토크 제한
- 최대 속도 제한
        ↓
서보 모터의 동역학
- 유효 관성
- 점성 마찰
- 쿨론 마찰
        ↓
실제 모터 응답 발생
- Position
- Velocity
- Torque
        ↓
엔코더 및 드라이브 피드백
        ↓
EtherCAT을 통해 WMX3로 전달
        ↓
WMX3 Data Log에 저장
- Command Position
- Feedback Position
- Feedback Velocity
- Feedback Torque
```

### 3.2 Newton 트윈의 모사 흐름

Newton 트윈은 별도의 Actuator 객체를 사용하지 않고, simulate_motor() 내부에서 액추에이터 동작(제어기·지연·토크 제한)과 물리 동역학(관성·마찰)을 함께 계산한다.

```text
Command Position (joint_target_pos)
        ↓
Delay (1~2사이클)
- EtherCAT 통신 및 연산 지연 근사
        ↓
PID 또는 PD
- 서보 드라이브 내부 제어 루프 근사
        ↓
Clamping
- 연속 토크 제한 (`continuous_torque_limit`)
- 순간 피크 토크 제한 (`peak_torque_limit`)
- 필요시 속도에 따른 토크 감소 특성 근사
        ↓
1-DOF 물리 모델
- 링크 및 회전체 관성
- 관절축 유효 관성
- 점성 감쇠
- 쿨롱 마찰
        ↓
Newton 시뮬레이션 출력
- Joint Position (joint_q)
- Joint Velocity (joint_qd)
- Actuator Torque (joint_f)
```

### 3.3 캘리브레이션 흐름

캘리브레이션은 WMX3 Data Log에서 취득한 실제 모터 응답과
Newton 트윈의 시뮬레이션 결과를 비교하여,
두 응답의 차이가 작아지도록 Newton 파라미터를 조정하는 과정이다.

```
WMX3 데이터 로그 로드 및 단위 변환
              ↓
시간축과 초기 위치 정렬
              ↓
정지 로그(아무 행동X)로 토크 노이즈 측정
              ↓
Step 입력 파형으로 delay 측정
              ↓
ramp에서 마찰 파라미터 초기값 추정
              ↓
Multi-Sine에서 관성 및 제어 게인 초기값 추정
              ↓
모든 파형을 사용해 전체 파라미터 미세 조정
              ↓
학습에 사용하지 않은 S-Curve로 검증
```

## 4. 시험 지령 프로파일

실제 모터의 과도응답과 주파수별 추종 특성을 모두 확인하기 위해
점대점 이동과 여러 주파수의 사인 시험을 수행한다.

| 시험 지령 | 수행 방식 | 프로젝트에서의 역할 |
|---|---|---|
| Step | 목표 위치를 순간적으로 변경하는 점대점 지령 | 지연 및 과도응답 추정 |
| 다양한 Sine | 주파수별 사인파 위치 지령 반복 | 관성 및 제어 게인 초기 피팅 |
| Ramp | 일정 속도로 증가·감소하는 위치 지령 | 점성·쿨롱 마찰 초기 추정 |
| S-Curve | 저크가 제한된 곡선형 위치 지령 | 피팅 후 미사용 응답 검증 |


## 5. 오차 지표 및 검증

WMX3 실측 출력과 Newton 시뮬레이션 출력을 비교하기 위해
다음 지표를 사용하거나, 필요에 따라 선택적으로 함께 확인한다.

### 5.1 기본 오차 지표

- 위치·속도·토크 궤적의 정규화 RMSE
- 위치·속도·토크 오차를 가중 평균한 전체 loss
- Step 응답의 상승시간(`rise time`) 차이
- Step 응답의 정정시간(`settling time`) 차이
- Step 응답의 오버슈트 차이
- 추종오차(`followingError`)의 RMS, 최대값, 분위수 비교

### 5.2 선택적 주파수 응답 비교

여러 주파수의 사인 시험 데이터를 이용하여
주파수별 응답 특성을 선택적으로 비교할 수 있다.

이 비교는 주파수영역에서 직접 피팅하는 과정이라기보다,
시간영역 피팅 결과를 추가로 해석하기 위한 보조 검증 지표에 가깝다.

- Gain 비교
- Phase 비교

### 5.3 검증

파라미터 피팅에 사용하지 않은 `held-out` 궤적을 Newton 트윈에 입력하고,
실측 응답과 시뮬레이션 응답의 오차를 비교하여 일반화 성능을 평가한다.

예를 들어 Step, Ramp, Multi-sine 로그로 파라미터를 조정한 뒤,
피팅에 사용하지 않은 S-Curve 로그에서 위치·속도·토크 오차와
응답 형상 차이를 확인할 수 있다.

```text
피팅에 사용한 궤적
→ Newton 파라미터 조정

피팅에 사용하지 않은 held-out 궤적
→ 캘리브레이션된 Newton 트윈에 입력
→ 위치·속도·토크 및 응답 형상 비교
→ 일반화 성능 평가
```

## 6. 프로젝트 범위 밖 항목

본 프로젝트는 무부하 단일 서보 모터의 1-DOF 디지털 트윈 캘리브레이션에 집중한다.
따라서 아래 항목은 현재 범위에 포함하지 않는다.

- GPU/CUDA 기반 대규모 병렬 최적화
- 10Hz 이상의 고주파 데이터를 적극 활용한 피팅
- Newton 기본 actuator 기반 모델과 직접 구현 모델의 체계적 비교 실험
- 외부 부하, 중력, 감속기, 축간 결합을 포함한 다축 로봇 동역학
- CR3A 로봇암의 전체 디지털 트윈 구축
