# 프로젝트 전체 구조

## 1. 프로젝트 목적과 범위

### 1.1 프로젝트 목적
WMX3 Data Log로 취득한 무부하 단일 서보 모터의 입력(Command Position)과 출력(Feedback Position·Velocity·Torque) 데이터를 기준으로
Newton 단일 모터 디지털 트윈의 파라미터를 피팅하여 실제 모터의 응답 특성을 재현하는 프로젝트이다.

### 1.2 프로젝트 범위
해당 프로젝트는 실제 서보 시스템 전체를 복제하는 것이 아닌, 무부하 단일 모터의 입력-출력 응답을 Newton 기반 디지털 트윈으로 근사하는 것을 목표로 한다.

Newton 트윈은 실제 장비의 모든 내부 구조를 복제하는 모델이 아니라,
Command Position에 대한 위치·속도·토크 응답을 유사하게 재현하기 위한 그레이박스 모델이다.


## 2. 시스템 구성 요소와 역할 경계

| 구성 요소 | 역할 |
|---|---|
| WMX3 마스터 | 이동 궤적을 생성하고, 매 통신 주기마다 CSP 방식의 Command Position을 서보 드라이브에 전송한다. 드라이브에서 전달받은 피드백 신호를 Data Log로 저장한다. |
| EtherCAT | WMX3 마스터와 서보 드라이브 사이에서 위치 지령과 피드백 데이터를 주기적으로 전달한다. |
| 서보 드라이브 | 수신한 Command Position을 내부 위치·속도·전류 제어 루프로 추종하고 모터 구동 토크를 발생시킨다. |
| 서보 모터 | 드라이브가 발생시킨 토크에 따라 회전하며, 관성과 마찰에 의해 실제 응답이 결정된다. |
| Newton 디지털 트윈 | 드라이브와 모터에서 나타나는 지연, 제어 응답, 제한, 관성 및 마찰을 파라미터로 근사한다. |

이 프로젝트에서 WMX3는 이동 궤적과 CSP 위치 지령을 생성하는 EtherCAT 마스터이다.  
실제 위치·속도·전류 제어 루프는 서보 드라이브 내부에서 수행된다.

따라서 Newton의 `ControllerPID` 또는 PD 모델은 WMX3의 제어를 모사하는 것이 아니라,
서보 드라이브 내부의 폐루프 응답을 단순화하여 근사하는 요소이다.


## 3. 전체 제어 흐름

이 프로젝트의 전체 흐름은 실제 서보 모터의 응답을 WMX3 Data Log로 취득하고,
동일한 Command Position을 Newton 트윈에 입력한 뒤,
두 시스템의 출력 차이가 작아지도록 트윈의 파라미터를 조정하는 과정으로 구성된다.

### 3.1 실제 장비의 제어 흐름

WMX3 마스터는 이동 궤적을 생성하고,
각 EtherCAT 통신 주기마다 CSP 방식으로 Command Position을 서보 드라이브에 전송한다.

```text
WMX3 마스터
- 이동 궤적 생성
- CSP Command Position 전송
        ↓
EtherCAT 통신
- 위치 지령 전달
- 통신 및 연산 지연 발생 가능
        ↓
서보 드라이브 내부 폐루프 제어
- 수신한 Command Position 추종
- 내부 위치·속도·전류 제어 루프 수행
- 모터 구동 토크 발생
        ↓
드라이브 제한 조건
- 최대 토크 제한
- 최대 속도 제한
        ↓
서보 모터의 동역학
- 유효 관성
- 점성 마찰
- 쿨론 마찰
        ↓
실제 모터 응답 발생
- Position
- Velocity
- Torque
        ↓
엔코더 및 드라이브 피드백
        ↓
EtherCAT을 통해 WMX3로 전달
        ↓
WMX3 Data Log에 저장
- Command Position
- Feedback Position
- Feedback Velocity
- Feedback Torque
```

### 3.2 Newton 트윈의 모사 흐름

Newton 트윈은 실제 서보 드라이브와 모터의 내부 구조를 모두 그대로 구현하는 것이 아니라,
입력–출력 응답에 영향을 주는 주요 요소를 Actuator와 물리 파라미터로 근사한다.

```text
Command Position (joint_target_pos)
        ↓
Delay (1~2사이클)
- EtherCAT 통신 및 연산 지연 근사
        ↓
ControllerPID 또는 PD
- 서보 드라이브 내부 제어 루프 근사
        ↓
Clamping
- 최대 토크 제한 (effort_limit)
- 필요시 속도에 따른 토크 감소 특성 근사
        ↓
1-DOF 물리 모델
- 링크 및 회전체 관성
- 관절축 유효 관성
- 점성 감쇠
- 쿨롱 마찰
        ↓
Newton 시뮬레이션 출력
- Joint Position (joint_q)
- Joint Velocity (joint_qd)
- Actuator Torque (joint_f)
```

### 3.3 캘리브레이션 흐름

캘리브레이션은 WMX3 Data Log에서 취득한 실제 모터 응답과
Newton 트윈의 시뮬레이션 결과를 비교하여,
두 응답의 차이가 작아지도록 Newton 파라미터를 조정하는 과정이다.

```text
WMX3 Data Log에서 실측 데이터 취득
- Command Position
- Feedback Position
- Feedback Velocity
- Feedback Torque
        ↓
Command Position 전처리 및 단위 변환
        ↓
동일한 Command Position을 Newton 트윈에 입력
        ↓
Newton 시뮬레이션 실행
        ↓
Newton 출력 계산
- Joint Position (joint_q)
- Joint Velocity (joint_qd)
- Actuator Torque (joint_f)
        ↓
WMX3 실측 출력과 Newton 출력 비교
        ↓
오차 지표 (## 4 참고)
- 위치/속도/토크 궤적의 정규화 RMSE 합
- 정정시간·오버슈트 차이
- 추종오차 비교
        ↓
트윈 파라미터 피팅
- 제어 게인 : kp, ki, kd, integral_max
- 지연 : delay_steps
- 토크/속도 한계 : effort_limit
- 기계 특성 : 유효 관성(J), 점성 마찰(b), 쿨롱 마찰(τc)

※ 토크 포화 effort_limit은 무부하 조건에서 식별하지 않고 데이터시트 값으로 고정한다.
※ 속도 한계 velocity_limit은 피팅을 한다면 할 수 있지만 토크 한계 피팅을 하는것으로 충분하다고 고려.
        ↓
다시 시뮬레이션
        ↓
오차가 충분히 작아질 때까지 반복
```

## 4. 시험 지령 프로파일

실제 모터의 과도응답과 주파수별 추종 특성을 모두 확인하기 위해
점대점 이동과 여러 주파수의 사인 시험을 수행한다.

| 시험 지령 | 수행 방식 | 프로젝트에서의 역할 |
|---|---|---|
| 점대점 이동 | 한 위치에서 다른 목표 위치까지 이동한 후 정지 | 가속·감속 및 정지 과정의 시간영역 응답 취득 |
| 여러 주파수의 사인 시험 | 주파수별 사인 지령을 각각 실행하고 로깅 | 주파수 변화에 따른 추종 응답 취득 |

### 4.1 점대점 이동

점대점 이동은 모터를 현재 위치에서 지정한 목표 위치까지 이동시킨 후
목표 위치에서 정지시키는 시험이다.

WMX3는 프로파일 기반으로 모터를 구동하므로,
목표 위치를 순간적으로 바꾸는 이상적인 스텝 대신
사다리꼴 또는 S-curve 형태의 이동 프로파일을 사용한다.

### 4.2 여러 주파수의 사인 시험

사인 시험은 Command Position을 사인파 형태로 반복 변화시키는 시험이다.

WMX3 사인 지령은 한 번의 시험에서 하나의 주파수를 사용하므로,
여러 주파수를 각각 개별적으로 실행하고 로깅한다.

```text
1 Hz 시험 실행 → 로그 저장
2 Hz 시험 실행 → 로그 저장
5 Hz 시험 실행 → 로그 저장
...
```

단일 주파수만으로는 모터의 전체 추종 특성을 확인하기 어려우므로,
데모기의 허용 범위 안에서 여러 주파수의 시험을 수행한다.




## 5. 오차 지표 및 검증

WMX3 실측 출력과 Newton 시뮬레이션 출력을 비교하기 위해 다음 오차 지표를 사용한다.

### 5.1 기본 오차 지표

- 위치·속도·토크 궤적의 정규화 RMSE 합
- 정정시간 차이
- 오버슈트 차이
- 추종오차(`followingError`) 비교

### 5.2 선택적 주파수 응답 비교

여러 주파수의 사인 시험 데이터를 이용하여 주파수별 응답 특성을 비교할 수 있다.

- Gain 비교
- Phase 비교

### 5.3 검증

파라미터 피팅에 사용하지 않은 `held-out` 궤적을 Newton 트윈에 입력하고,
실측 응답과 시뮬레이션 응답의 오차를 비교하여 일반화 성능을 평가한다.

```text
피팅에 사용한 궤적
→ Newton 파라미터 조정

피팅에 사용하지 않은 held-out 궤적
→ 캘리브레이션된 Newton 트윈에 입력
→ 실측 출력과 시뮬레이션 출력 비교
→ 일반화 성능 평가
```
